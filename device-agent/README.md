# WORA Local Device Agent — foundation reference

زوج هذا الوكيل خفيفًا مع WORA ليرى التطبيق جهازك كـ"حي"، دون أن يقرأ أي شيء منه.

## الاقتران
1. في WORA → **النظام** → **الحوكمة والأجهزة** → اسم الجهاز → «طلب اقتران».
2. انسخ الرمز (يُعرض مرة واحدة) واسم الجهاز المعروض.
3. من جهازك:
   ```bash
   node wora-device-agent.mjs --api http://<wora-host>:4173 --device <device-id> --code <الرمز> --once
   ```
   سترى تشخيصًا محليًا (المعالج، الحمل، الذاكرة، مدة التشغيل) **يطبع محليًا ولا يُرسل**.
4. شغّل بدون `--once` ليبقى متصلًا بنبض كل ٦٠ ثانية.
5. في أي وقت: WORA → **الحوكمة والأجهزة** → «إلغاء» بجانب الجهاز — آخر نبضة تُرفض، ويخرج الوكيل نهائيًا.

## ما لا يفعله أبدًا
- لا يقرأ ملفاتك، شاشتك، لوحتك، متصفحك أو شبكتك.
- لا يرسل التشخيص إلى الخادم — التشخيص محلي فقط.
- لا ينفذ أوامر من أي مصدر. لا توجد قناة أوامر في هذه النسخة.
- البصمة `fingerprint` هاش مشتق من هوية الجهاز — لا يحتوي عليها.

## المتطلبات
Node.js ≥ 18.21. لا توجد اعتماديات. يعمل على Linux/macOS/Windows.
