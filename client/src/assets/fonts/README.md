# Wora Arabic Mono

The regular and bold WOFF2 files are Arabic-only builds of Abdullah Arif's [Kawkab Mono v0.501](https://github.com/aiaf/kawkab-mono/tree/v0.501), licensed under the [SIL Open Font License](../../../public/assets/font-licenses/OFL-Kawkab-Mono.txt).

The upstream Glyphs source is unchanged in its repository. For this web build, FontMake compiled the regular and bold instances (with legacy quoted feature strings escaped and old feature text preserved verbatim). FontTools retained the Arabic Unicode glyphs, join controls and OpenType shaping tables, and renamed the family to **Wora Arabic Mono** before WOFF2 compression. The CSS uses IBM Plex Mono for Latin and IBM Plex Sans Arabic for any missing Arabic glyphs.
